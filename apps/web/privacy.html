Privacy Policy

Last Updated: November 12, 2026 · Effective Immediately

TL;DR: The Developer Privacy Promise

NextShare is engineered as a zero-account, zero-tracking, privacy-first developer utility. We do not require signups, we do not track your browsing habits, we do not use marketing trackers or analytics cookies, and all temporary shares are automatically permanently purged upon expiration.

01 Zero Account & No Registration

NextShare operates entirely without user accounts. You will never be asked to provide your name, email address, password, phone number, or payment details. Because we do not have accounts, we have no personal profiles to sell, monetize, leak, or share with data brokers.

02 Data We Collect & Store

We only store data strictly required to deliver the core sharing utilities you invoke:

  • Shortened URLs: Original destination URL, custom or generated short code, click count, and optional expiration timestamp.
  • Shared Files: Encrypted file payload, original file name, MIME type, file size, optional password hash (Scrypt), download counter, and expiration date.
  • Code Pastes: Code snippet, language syntax tag, optional title, view count, expiration window, and burn-after-read status.
  • User Feedback (Optional): If you submit feedback, we record your star rating, optional review comment, optional display name, and tool tag to improve the service.

03 Automated Data Deletion & Retention

All shared assets on NextShare are designed to expire and be permanently scrubbed:

• Burn-After-Read Pastes : Destroyed immediately after the 1st view (zero disk/cache retention). • Ephemeral Files : Permanently deleted when max downloads or expiration TTL is hit. • Expired Short URLs : De-indexed from Redis cache and flagged inactive upon expiration.

Once a file or paste expires, its raw bytes are unlinked from storage and cannot be restored by anyone, including the NextShare engineering team.

04 Security & Encryption Standards

All data in transit is protected using Industry-Standard TLS 1.3 encryption. Passwords applied to files or code pastes are hashed using computationally hardened Scrypt derivation before persistence—passwords are never stored in plaintext.

05 Cookies & Local Storage (Offline PWA)

NextShare does not use third-party tracking cookies, advertising beacons, or surveillance pixels (no Facebook Pixel, no Google Analytics tracking). We use standard browser client storage strictly for functional execution:

  • IndexedDB: Stores your local offline queue so that links or pastes drafted offline can sync automatically when your device reconnects to the network.
  • LocalStorage: Saves your local copy history on your device only—this history is never synced to our servers without your action.

06 Infrastructure & Sub-processors

NextShare utilizes verified infrastructure providers for secure, high-uptime delivery:

  • Vercel: Static Edge network hosting and CDN caching.
  • Render: API compute layer containerized via Docker.
  • MongoDB Atlas: Encrypted database cluster with isolated VPC peering.
  • Redis: Sub-millisecond ephemeral cache with automatic TTL evictions.
