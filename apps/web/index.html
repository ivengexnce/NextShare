// TextService.create — simplified
const create = async (payload: PasteInput) => {
   const code = generateShortCode();
   const paste = await TextRepository.create({...payload, code});
   if (!payload.burnAfterRead) {
     await redis.set(`paste:${code}`, paste, TTL);
  }
   return paste;
};

How it works

From paste to link
in four steps.

Under the hood, every share is a full round-trip through Vite on the frontend, Express on the API, Redis for speed, and MongoDB for permanence.

1

Paste or drop

Enter a URL, drop a file, or paste code into the React app. Zustand manages local state while you type.

2

API creates it

Vite proxies the request to Express. The service validates it, generates a short code, and writes to MongoDB first.

3

Redis caches it

The result is written to Redis with a TTL. Every subsequent redirect or fetch hits the cache, not Mongo.

4

Share the link

You get a short URL back. Analytics, visitor deduplication via Redis Sets, and expiry all run automatically.

FAQ

Frequently Asked Questions

Direct answers to technical questions about NextShare architecture, privacy guarantees, encryption, and developer utilities.

What is NextShare and why should I use it over commercial sharing tools?

+

NextShare is an open-source, privacy-first developer sharing suite combining custom URL shortening with sub-100ms Redis caching, client-side encrypted file sharing up to 50MB, and a syntax-highlighted code pastebin. Unlike commercial utilities like Bitly or WeTransfer, NextShare requires no registration, displays zero ads, collects no tracking cookies, and never places limits behind paywalls.

Do I need to sign up, provide an email, or create an account?

+

No account, email, or personal identity is required. NextShare is designed as a frictionless anonymous developer tool. There are zero tracking scripts, third-party analytics pixels, or login gates. When you upload a file or create a paste, a cryptographically secure private delete token is returned to you so you can permanently wipe your data at any time.

Does NextShare work offline without an active internet connection?

+

Yes. NextShare is a certified Progressive Web App (PWA) with Service Worker precaching. Shortened links and code pastes drafted while offline are queued locally in browser IndexedDB storage and automatically synchronized with the server as soon as network connectivity is restored.

How fast are short link redirects and how do custom aliases work?

+

Redirects resolve in under 100ms. NextShare leverages an in-memory Redis cache to serve HTTP 301 redirects instantly without querying the primary database. You can specify a custom alphanumeric alias (3 to 20 characters) or receive an ultra-short 5-character NanoID link (e.g. nextsharebymeet.vercel.app/s/KXKFN) with real-time, privacy-friendly click analytics.

Does NextShare track visitors or inject ads into shortened URLs?

+

No. NextShare never injects interstitial ads, countdown landing screens, or tracking pixels into shortened URLs. Every link performs a direct HTTP 301 redirect to the destination URL while tracking only aggregated, anonymized metrics (total clicks and approximate unique visitors) without storing personal IP addresses.

What file types and maximum upload sizes does NextShare support?

+

NextShare supports file uploads up to 50MB across document, archive, media, and developer formats, including ZIP, TAR, 7Z, PDF, DOCX, XLSX, JSON, CSV, images, audio, and source code. Executable file extensions (.exe, .bat, .sh) are blocked by upload middleware to prevent malicious distribution.

Can I set passwords, expiration windows, and download limits on files?

+

Yes. You can optionally protect any file upload with a custom password verified via salted Scrypt key derivation, choose an expiration window (1 hour, 1 day, or 7 days), and enforce a strict download cap (1, 5, or 10 downloads). Once the download cap or TTL expiration is reached, the file and its metadata are permanently expunged.

How does the burn-after-read code pastebin protect sensitive data?

+

When Burn-After-Read is enabled, the code snippet is fetched directly from MongoDB and atomically destroyed upon first retrieval. It completely bypasses the Redis cache so no copies persist in memory, and integrates with the browser sendBeacon API to trigger immediate deletion if the tab is closed, ensuring API tokens, keys, and secrets are never read twice.

Which programming languages and syntax highlighting modes are supported?

+

NextShare supports full syntax highlighting across 23+ major languages, including JavaScript, TypeScript, Python, Go, Rust, Java, C, C++, C#, PHP, Ruby, Swift, Kotlin, SQL, HTML, CSS, JSON, YAML, Markdown, Bash/Shell, Dockerfile, and GraphQL, complete with line numbering and one-click clipboard copying.

Can I self-host NextShare using Docker on my own server?

+

Yes. NextShare is 100% open-source under the MIT license. You can self-host the entire production stack (React frontend, Express API, MongoDB, and Redis) on any VPS or private server with a single command: docker compose up -d. Custom domains, storage paths, and rate limits are fully configurable via environment variables.
